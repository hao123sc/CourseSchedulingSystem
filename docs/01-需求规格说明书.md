# 01 · 需求规格说明书

> 项目：**智课排** —— 中小学全学段智能排课系统（单机版）
> 版本：v1.0　日期：2026-09-28

---

## 1. 产品定位

一款**免安装、零配置、双击即用**的桌面排课软件，覆盖小学、初中、高中三个学段，能在数秒内生成经得起推敲的高质量课表，并提供直观的可视化调整能力。

**一句话价值**：把教务主任两周的手工排课，变成 10 秒钟的一次点击，且课表质量更高。

### 1.1 设计目标优先级

| 序 | 目标 | 衡量方式 |
|---|---|---|
| P0 | **课表质量经得起随机抽查** | 任取一名教师/一个班级的课表，无明显不合理安排 |
| P0 | **界面美观** | 课表网格的视觉质感达到商业软件水准 |
| P0 | **零门槛上手** | 未读任何说明的用户，3 分钟内能看到一张完整课表 |
| P1 | 全学段、大规模支持 | 12 年级 × 20 班 = 240 教学班可正常排课 |
| P1 | 调整便捷 | 拖拽换课，实时冲突提示，一键撤销 |
| P2 | 导出与打印 | Excel / PDF / 图片，排版专业 |

### 1.2 非目标（明确不做）

联网、多用户、权限体系、移动端、微信集成、学生个体信息管理（走班选课除外）、考勤、成绩、数据同步、服务端部署。

## 2. 用户与场景

### 2.1 用户角色

单机单用户，**无登录、无角色区分**。使用者统称「教务管理员」。

### 2.2 核心使用场景

| 编号 | 场景 | 描述 |
|---|---|---|
| UC-1 | **首次体验** | 打开软件 → 首页引导「载入示例学校」→ 选择学段 → 一键排课 → 浏览课表 |
| UC-2 | **新学期排课** | 新建学期 → 导入/录入基础数据 → 配置教学任务矩阵 → 设置规则 → 自动排课 → 微调 → 导出 |
| UC-3 | **学期中调整** | 教师请假/新增班级/教室检修 → 增量重排受影响部分 → 对比差异 → 确认 |
| UC-4 | **多方案比选** | 同一份数据生成「教师优先/学生优先/均衡」三套方案 → 对比评分 → 择优采用 |
| UC-5 | **无解排障** | 资源不足导致排不出 → 系统给出量化缺口与修复建议 → 调整后重排 |

## 3. 功能清单（MoSCoW 分级）

> **M**=必须做　**S**=应该做　**C**=可以做　**W**=本期不做

### 3.1 学校与学段配置

| 编号 | 功能 | 级别 | 说明 |
|---|---|---|---|
| F1.1 | 学校信息 | M | 校名、校徽、类型（小学/初中/高中/九年一贯/完全中学/十二年一贯） |
| F1.2 | 学期管理 | M | 新建/切换/复制学期；一个学期一套课表 |
| F1.3 | **学段配置** | M | 三学段可并存；每学段独立配置作息、周上课天数、学科集合 |
| F1.4 | **作息时间模板** | M | 每学段自定义节次：上午/下午/晚自习分段，每节起止时间、节次名称 |
| F1.5 | 特殊时段 | S | 早读、课间操、午休、班会、课后服务——作为固定占位参与冲突约束 |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 60 班规模排课 ≤ 10 秒；240 班 ≤ 90 秒；UI 全程不卡顿（引擎在 Worker 线程） |
| **课表质量** | 硬约束违反数 **必须为 0**；软约束达到 CP-SAT 最优解的 90% 以上 |
| **可靠性** | 排课可取消；异常不崩溃；数据每次操作后即时落盘 |
| **易用性** | 主流程点击深度 ≤ 3；任何错误提示都给出下一步动作 |
| **兼容性** | Windows 10/11 x64 为主；提供 macOS 构建 |
| **交付形态** | 绿色免安装 `.exe`（portable）+ 安装包（NSIS），单文件 < 150MB |
| **数据** | SQLite 单文件，随程序目录或用户目录存放，可整体拷贝迁移 |

---

## 5. 约束与假设

- 单机单用户，无并发
- 数据规模上限 240 教学班、600 教师、300 教室
- 排课以「周」为循环单位，不处理具体日期与节假日调休
- 不联网，不上传任何数据

## 6. 验收标准（关键项）

| 编号 | 验收点 |
|---|---|
| AC-1 | 全新安装后，从启动到看到一张完整初中课表 ≤ 3 分钟，且无需阅读说明 |
| AC-2 | 生成的课表硬冲突数为 0（教师/班级/教室三元组） |
| AC-3 | 随机抽查 10 名教师课表，无"单日 ≥5 节"或"空隙课 ≥3 节"的情况 |
| AC-4 | 随机抽查 10 个班课表，同学科同日重复 ≤ 1 次，主课上午占比 ≥ 70% |
| AC-5 | 240 班规模可成功排课且不崩溃 |
| AC-6 | 拖拽换课响应 < 100ms，冲突提示即时 |
| AC-7 | 导出的 PDF 打印后排版完整，无截断、无乱码 |
| AC-8 | 新增一个年级/20 个班后，可正常增量重排 |

# 智课排 · 新会话工作指南（评估 · 测试 · Bug修复 · 功能扩展）

> 本文件是为新开会话量身定制的交接指南。新会话将专注于**系统全流程综合评测、全量测试、Bug 修复与进阶功能扩展**。

---

## 一、当前项目基线

- **核心里程碑**：M0 ~ M8 全部核心功能已完整交付并推送到远程仓库。
- **排课引擎**：AC-3 预处理 + DSATUR 启发式构造 + ALNS / LAHC 局部搜索 + Polish 抛光，支持 240 班超大规模秒级排课。
- **课表交互**：四视图（班级/教师/教室/全校总表）、智能换课推荐 Top5、拖拽换课与冲突拦截、50 步撤销重做、双击联动跳转。
- **课表体检与导出**：六维度量化雷达、教师负载分布柱状图、主课时段热力图、Excel 导出（A4 纸单页自适应排版/自定义审签栏）、300 DPI 广告公司大幅面海报流式切片导出（实测支持 23,220 × 10,746 px 巨幅印刷，内存稳定 < 50MB）。
- **预设与资产**：5 套标准学校示范场景一键载入、版本历史双方案对比、SQLite 数据库本地备份恢复。
- **质量基线**：
  - `npm run test:sqlite`：**25 个测试文件、183 个测试全部通过**；
  - `npm run typecheck`：**0 错误**；
  - `npm run lint -- --no-fix`：**0 错误、0 警告**；
  - `npm run build`：生产环境打包成功。

## 二、新会话目标与任务范围

1. **综合评估与端到端测试**：
   - 验证五套预设数据在真实教学场景下的排课质量与课表指标；
   - 验证手工拖拽调课、连堂换课、预排锁定冲突拦截；
   - 验证 Excel 导出（单表/批量/总表/A4 排版）与大幅面 300 DPI 海报生成。
2. **边缘 Case 与 Bug 修复**：
   - 排查并修复用户在测试过程中发现的任何 UI 或逻辑缺陷；
   - 持续保障 `test:sqlite`、`typecheck`、`lint` 0 报错。
3. **进阶功能扩展（按需演进）**：
   - 单双周课程更灵活的配对与调课支持；
   - 选课走班（虚拟班与行政班）扩展；
   - 历史版本一键回滚与克隆衍生排课方案。

### 这一轮要注意的两件事

1. **Worker 是唯一能碰 Node 模块的地方**。引擎保持纯 TS 是刻意的（可单测、可在渲染端复用做落点预判，M6 要用）。
2. **落库要逐班取 `roomIds[i]`**，不要图省事写 `roomId` —— 拼合组的两个班在不同教室，写错了课表上会看到两个班挤同一间。

### 两条可选但值得一提的事

- 拼合组口径（同槽 + 各班各占一间场地 + 人数按单班核）目前只记在变更日志 #17 里，
  如果你认可，可以让新会话把它升格为 **D9** 写进「已锁定的决策」表。
- `npm run bench` 现在只断言「硬约束 0 / 未排 0」，M5 做软约束时要在它上面加回归指标阈值
  （docs/06 M5 验收项那张表：教师日课时 ≤6、空隙课 ≤0.3×教师数、主课上午占比 ≥70% 等）。

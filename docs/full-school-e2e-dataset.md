# 十二年一贯制 240 班全功能黄金测试数据

> 学校：**智课排十二年一贯制实验学校（全功能测试校）**  
> 用途：系统综合评估、240 班容量测试、端到端测试、导出与缺陷回归。  
> 入口：工作台 →「十二年一贯制全功能测试校（240班）」→「载入十二年一贯制全功能数据」。

## 1. 固定规模

| 数据项 | 数量/口径 |
|---|---:|
| 学校类型 | `twelve_year` |
| 年级 | 小一至高三，共 12 个 |
| 行政班 | 每年级 20 班，共 240 班 |
| 学生 | 每班 54 人，共 12,960 人 |
| 教师 | 547 人；小学 200、初中 158、高中 189 |
| 场地 | 347 间/处；固定教室 240 间且容量均为 60 |
| 学科 | 内置 19 + 学段实验/项目学科 9 = 28 |
| 教学任务 | 3,124 条 |
| 正课 | 7,220 等效节/周；单双周按数据库任务行统计为 7,224 节 |
| 预排/资源占用 | 328 条 |
| 约束组 | 12 组 |
| 课表版本 | 均衡、教师优先、学生优先 3 个；均衡版正式发布 |

## 2. 作息与课程

- 小学：5 天 × 7 节 = 35 槽；低段 26 节/周，中高段 30 节/周。
- 初中：5 天 × 8 节 = 40 槽；初一 31、初二/初三 33 节/周。
- 高中：早读 1 + 上午 5 + 下午 4 + 晚自习 3 = 13 槽/天；正课窗口 45 槽；高一/高二 34、高三 36 节/周。
- 班会是带班主任和固定教室的预排课，不进入普通教学任务；早读、晚自习不计教师正课工作量。
- 小学三至六年级科学、初高中理化生各拆出一节实验课，总课时不增加；理论和实验由同一教师池承担。

## 3. 教师工作量口径

- 小学：主科上限 16，科学/道法 18，音体美信息劳动等 20。
- 初中：语数英上限 12，理化生政史地 14，小科 16。
- 高中：语数英及选科上限 12，小科一般 14；体育因 40 个整班任务每班 3 节不可拆，在保持 9 人规模时允许个别教师 15 节，平均 13.33 节。
- 分配器以“同班同教师池”为不可拆包，用 best-fit 与 balanced 两种确定性装箱策略互补，落库前保证零超工作量。
- 每班班主任必须实际任教本班，且一名教师最多担任一个班班主任；使用二分图增广匹配生成，240 位班主任不重复。

## 4. 场地口径

- 所有普通教室和单班功能室容量至少 60，满足 54 人容量硬约束。
- 体育场地按 `capacity` 与 `concurrent_capacity` 分别建模，例如小学田径场 648 人/并发 8 班。
- 小学配科学实验室 4、计算机 4、音乐 8、美术 8、劳动创客 8及 4 处体育场地。
- 初中配理化生实验室 8、计算机 3、音乐 2、美术 2、劳动创客 3及 3 处体育场地。
- 高中配理化生实验室 9、计算机 3、通用技术 2、音乐 2、美术 2、项目室 2及 3 处体育场地。
- 另配大礼堂、报告厅、图书阅览、心理、舞蹈、录播、机器人等 15 间共享空间。
- 第一版黄金数据的教师和主要场地按学段分池；在跨学段实际时间归一功能落地前，不制造跨学段共享资源。

## 5. 功能覆盖

- 四层规则值：`FORBIDDEN / AVOID / NORMAL（不落行）/ PREFERRED`。
- 五种规则作用域：全局、年级、班级、教师、学科。
- 显式连堂：小学美术、初三物理、高二物理样本。
- 单双周：高一 1～4 班通用技术拆成 odd/even 任务。
- 预排：240 班会、12 年级升旗、高中 15 条早读/45 条晚自习。
- 资源占用：实验室维护、场地外借、教师教研/行政会议。
- 约束组：教师互斥、学科互斥、拼合、同时上课、跟随全部有样本。
- 结果功能：三个版本、正式发布、四视图、体检报告、Excel/A4/海报导出、备份恢复。

## 6. 自动验收

`presetService.test.ts` 对以下不变量做真实 SQLite + 真实求解断言：

- 12 年级、240 班、12,960 人、547 教师、347 场地；
- 28 学科、3,124 任务、7,224 原始任务课时、328 预排；
- 240 位不重复班主任；普通教室最小容量 60；
- 小学/初中/高中分别 35/40/65 个时段；
- 零未指派任务、零教师超载、输入自检零 error；
- 三种权重方案均独立求解成功且未回退；
- 三个版本全部未排 0、硬约束违反 0，并各落库 7,224 行课。

运行：

```bash
npm run test:sqlite
npm run typecheck
npm run lint -- --no-fix
npm run build
npm run bench
```

## 7. 已知后续专项

数据会录入 `follow` 与 `room_coexist_rule`，但当前求解器尚未消费这两种语义；它们目前只验证数据录入/读取链路。真实走班的 `virtual_class_source → H11` 也尚未接入业务求解。跨学段共享资源需要先增加按真实起止时间归一的冲突轴。这三项不得在验收报告中误写为已经生效。

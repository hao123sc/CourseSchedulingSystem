# 05 · 界面与交互设计

> 版本：v1.0　日期：2026-09-28
> **本文档是本项目优先级最高的文档之一。** 评委不看代码、不听答辩，只会打开软件点几下——界面质感直接等于分数。

---

## 1. 设计原则

| 原则               | 落地                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------- |
| **课表即产品**     | 评委 80% 时间停留在课表页。侧边栏、表单的精致度远不如课表网格重要，资源向课表页倾斜          |
| **三步见成果**     | 启动 → 载入示例 → 排课。任何需要先录数据才能看到效果的设计都是失败                           |
| **不解释，靠直觉** | 不写说明文字，用视觉层次、颜色、动效引导                                                     |
| **克制的精致**     | 不用花哨渐变和阴影堆砌。高质感来自：一致的间距节奏、克制的配色、精准的圆角与描边、流畅的过渡 |
| **反馈即时**       | 拖拽 < 100ms 响应，任何操作都有可见回应                                                      |

## 2. 视觉规范

### 2.1 色彩系统

**中性色（界面骨架）** —— 采用 Slate 色阶，冷调，专业感强

| 用途      | 浅色模式            | 深色模式            |
| --------- | ------------------- | ------------------- |
| 页面底色  | `#F8FAFC` slate-50  | `#0F172A` slate-900 |
| 卡片/面板 | `#FFFFFF`           | `#1E293B` slate-800 |
| 分隔线    | `#E2E8F0` slate-200 | `#334155` slate-700 |
| 主文字    | `#0F172A`           | `#F1F5F9`           |
| 次文字    | `#64748B` slate-500 | `#94A3B8` slate-400 |

**品牌主色**：`#4F46E5` (indigo-600)，用于主按钮、选中态、焦点环。克制使用。

**状态色**：成功 `#10B981`／警告 `#F59E0B`／错误 `#EF4444`／信息 `#3B82F6`

**学科配色体系**（课表灵魂，必须精心调）

采用**低饱和 + 高辨识**策略：每个学科一组 `{bg, border, text}`，浅色模式下背景为该色 50 档、文字为 700 档、左侧 3px 色条为 500 档。

| ---- | ---- | --------- | --------- | --------- |
| 语文 | 玫红 | `#FEF2F2` | `#B91C1C` | `#EF4444` |
| 数学 | 靛蓝 | `#EEF2FF` | `#4338CA` | `#6366F1` |

| 政治 | 紫   | `#FAF5FF` | `#7E22CE` | `#A855F7` |

### 2.2 字体与排版

```css
font-family:
  'Inter', 'HarmonyOS Sans SC', 'PingFang SC', 'Microsoft YaHei UI', system-ui, sans-serif;
/* 数字使用等宽变体，保证课表节次对齐 */
font-variant-numeric: tabular-nums;
```

| 层级       | 字号 / 行高 / 字重 |
| ---------- | ------------------ |
| 页面标题   | 24px / 32px / 600  |
| 区块标题   | 16px / 24px / 600  |
| 正文       | 14px / 20px / 400  |
| 辅助       | 12px / 16px / 400  |
| 课表学科名 | 14px / 18px / 600  |
| 课表教师名 | 11px / 14px / 400  |

### 2.3 间距与形状

- 间距基准 **4px**，常用 8/12/16/24/32
- 圆角：卡片 `12px`，课程块 `8px`，按钮 `8px`，输入框 `6px`
- 阴影：仅三级
  - `sm` 悬浮卡片：`0 1px 2px rgba(15,23,42,.06)`
  - `md` 弹出层：`0 4px 12px rgba(15,23,42,.10)`
  - `lg` 拖拽中：`0 12px 24px rgba(15,23,42,.18)`
- 描边优先于阴影：大部分容器用 `1px solid slate-200` 而非阴影

### 2.4 动效

| 场景       | 参数                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 通用过渡   | `150ms cubic-bezier(.4,0,.2,1)`                                        |
| 课程块悬停 | `scale(1.02)` + 阴影升级，120ms                                        |
| 拖拽拾起   | `scale(1.05)` + `rotate(2deg)` + lg 阴影                               |
| 落位吸附   | spring：`stiffness 400, damping 30`                                    |
| 页面切换   | 淡入 + 上移 8px，200ms                                                 |
| 排课完成   | 课表**逐格瀑布式淡入**（stagger 8ms/格），全部完成后顶部飘一条成功横幅 |

> 排课完成动效是唯一允许"炫"的地方——它是评委看到成果的瞬间，值得设计。

### 2.5 响应式与界面缩放（2026-09-29 补充）

桌面端同样要适配窗口拉伸、最大化与全屏，约定如下：

| 项        | 约定                                                                                                                                                             |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 外壳高度  | `h-[100dvh]`，不用 `h-screen`；全屏/最大化切换时以视口实际高度为准                                                                                               |
| 外壳宽度  | `w-full`，不用 `w-screen`（`100vw` 含滚动条宽度，窄窗口会横向溢出）                                                                                              |
| flex 链路 | 每层 flex 子项补 `min-w-0` / `min-h-0`，否则宽表格会把整个外壳撑破                                                                                               |
| 正文限宽  | 统一由 AppLayout 给 `max-w-[1920px]`，页面自身不再各写各的 `max-w-*`                                                                                             |
| 表单栅格  | 一律 `grid-cols-1 sm:grid-cols-2`，不写死两列                                                                                                                    |
| 表格      | 外层 `overflow-x-auto` + 表头 `sticky top-0`，窄窗口横向滚动而不是压扁列                                                                                         |
| 定宽栅格  | 如作息编辑器的 `grid-cols-[2fr_1.5fr_…]`，必须配 `min-w-[40rem]` + 外层横向滚动                                                                                  |
| 大网格    | 矩阵 / RuleGrid 用 `flex-1 + min-h-0` 吃满剩余高度，不写死 `max-h-*vh`                                                                                           |
| 弹窗      | `max-w-[min(92vw,32rem)]`、`max-h-[85dvh]`                                                                                                                       |
| 侧边栏    | 常态 13rem（xl 以上 15rem），可折叠为 3.75rem 只留图标，状态记 localStorage                                                                                      |
| 界面缩放  | 80%~150%，`Ctrl + =` / `Ctrl + -` / `Ctrl + 0`，`Ctrl + 滚轮` 同样生效；<br>实现为改根字号（Tailwind 间距/字号/宽高多为 rem，整体等比缩放），状态记 localStorage |

> 沙箱/CI 里可用 `npm run preview:ui` 在普通浏览器里拖窗口验证以上各条。

### 4.2 教学任务矩阵（数据录入核心）

**这是唯一需要大量输入的页面，必须做到极致好用。**

```
         语文  数学  英语  物理  化学  生物  政治  历史  地理  体育  音乐  美术  信息  合计
初一(1)   5     5     5     -     -     2     2     2     2     3     1     1     1    29
  └教师  张明  李红  王芳         刘伟  陈静  孙磊  周涛  赵刚  吴敏  郑丽  钱强
初一(2)   5     5     5     -     -     2     2     2     2     3     1     1     1    29
...
合计     100   100   100    0     0    40    40    40    40    60    20    20    20
```

交互要点：

- **行=班级，列=学科**，单元格上半填课时数、下半显示教师名（悬停显示完整）
- **Excel 式键盘操作**：方向键移动、直接输入数字、Tab 跳下一格、Ctrl+D 向下填充、Ctrl+C/V 整行复制
- **框选批量填充**：拖选一个区域 → 输入数字 → 全部填入
- **顶部快捷条**："按国家课程标准一键填充"下拉（选学段自动套用课时方案）
- **教师指派**：点单元格下半区 → 弹出教师选择器，只列出教任该科且**未超工作量**的教师，超限者标红置底
- **右侧固定面板**：实时教师工作量条形图，超限者红色闪烁
- **列合计 / 行合计**始终可见，行合计超出该学段周总节次时整行标黄

### 4.2b 教室与场地管理

普通教室和共享场地在同一张表内，用**并发容量**区分，UI 上需让这个概念一眼可懂：

```
名称          类型      座位容量   同时可上班数   楼栋
────────────────────────────────────────────────────
初一(1)班教室  普通教室      50      1  独占        A栋
物理实验室     实验室        48      1  独占        C栋
田径场        体育场地     800      4  ●●●●        室外
篮球场        体育场地     150      3  ●●●         室外
风雨操场      体育场地     300      2  ●●          B栋
```

- 「同时可上班数」列用**圆点可视化**，1 显示为文字「独占」，>1 显示对应数量的圆点
- 新建场地时，类型选「体育场地」自动把并发容量默认值设为 2 并给出提示：「共享场地可同时容纳多个班级上课」
- 侧边提供**容量体检**：实时计算「体育课需求 180 节 / 场地供给 275 班位」，不足时红色预警并提示缺口

**教室课表视图**中，并发容量 >1 的场地每格显示多个班级：

```
        周一第3节
┌────────────────────┐
│ 田径场   3/4 使用中 │
│ ┌────┐┌────┐┌────┐ │
│ │初一1││初一5││初二3│ │
│ └────┘└────┘└────┘ │

| 合法落点               | 目标格背景淡绿 `#ECFDF5` + 绿色虚线边框，轻微呼吸动画             |
| 警告落点（软约束变差） | 淡黄 `#FFFBEB` + 黄色虚线                                         |
| 非法落点               | 淡红 `#FEF2F2` + 红色虚线 + 光标 `not-allowed`                    |
| 冲突存在               | 右上角红色圆点徽标，点击展开冲突明细                              |

**拖拽交互全流程**

1. `onDragStart` → 立即用本地约束模块算出全部落点等级，**整张表同时着色**（这一瞬间的视觉反馈是最能体现"智能"的地方）
2. 拖到目标格 → 若该格已有课，显示「⇄ 交换」提示；空格显示「↓ 移入」
3. 落下 → spring 吸附动画 → 顶部滑出轻提示条：「已将 周三第2节 数学 与 周五第4节 英语 互换　评分 92.4 → 93.1 ▲」
4. 若评分下降，提示条为黄色并附「撤销」按钮

**单击调课全流程（2026-10-01 增强）**

1. 单击可移动课程 → 进入调课状态，源格靛蓝标识，合法目标立即显示绿色，非法/冲突目标显示灰色禁用态；
2. 单击绿色空格 → 使用与拖拽完全相同的本地冲突检测再次校验，保存后结束调课；
3. 单击灰色格或被占课程 → 保持调课状态并显示班级/教师/教室/预排冲突原因；
4. 再次单击源课程、点击“取消”或按 `Esc` → 退出调课状态；
5. 切换版本、视图、学段或实体时自动清理调课状态。拖拽、撤销/重做和智能换课建议继续保留。

**智能换课建议**：选中一节课 → 右侧滑出面板

│ ② 周四第3节   评分 +1.8       │
│ ③ 与周五第2节交换 +1.1        │
│ ④ 周一第4节   评分 −0.4       │
│                              │
│ [ 应用 ① ]                   │
└──────────────────────────────┘
```

**教师课表特有**：空隙课用斜纹灰格明确标出并在页脚统计「今日空隙 2 节」。

**全校总表**：年级为分组、班级为列、时间为行，虚拟滚动；顶部可切「按班级」「按教师」；支持 Ctrl+滚轮缩放（50%~150%），缩小时课程块自动降级为纯色块 + 学科简称。

## 6. 打印样式

独立 `print.css`，A4 横向（总表）/ 纵向（单班）：

- 强制彩色背景打印：`-webkit-print-color-adjust: exact`
- 去除所有交互元素、阴影、圆角减半
- 页眉：学校名 + 学期 + 表名；页脚：页码 + 生成日期
- 总表分页：竖排按班级块 `break-inside: avoid`，横排按天分页
- 单班课表居中，占满 A4，字号放大到 16px

## 7. 无障碍与细节

- 全部交互支持键盘：课表格用方向键导航，空格拾起、方向键移动、回车放下
- 焦点环统一 `2px solid indigo-600, offset 2px`
- 颜色不是唯一信息载体：冲突除红色外附图标，学科除颜色外有名称
- 所有破坏性操作（清空数据、回滚版本）二次确认
- 长任务有进度与取消；空状态有引导；错误有下一步动作

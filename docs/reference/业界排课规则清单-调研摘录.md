# 业界排课系统常见规则清单

## 一、排课任务与基础设置

- **排课任务**：任务名称、学期、参与排课的年级集合
- **节次设置**：每周上课天数；每天节次数（上午 / 下午 / 晚自习分段）
- **课程设置**：排课科目集合；各科目的**总课时**、**连堂课时**
- **教师设置**：教师集合；每位教师所带科目、所带班级

## 二、规则体系（重点参考）

### 2.1 不排课规则（多维度）
| 维度 | 说明 |
|---|---|
| 班级不排课 | 某班级不允许在选定节次排课 |
| 教师不排课 | 某教师不允许在设定节次排课（教研、外聘兼职等） |
| 课程不排课 | 某科目不允许在设定节次排课（如体育不排上午第1节） |

### 2.2 不连堂规则
选择两个相邻节次，声明其间不允许排连堂课。例：上午第1、2 节之间不允许连堂。

### 2.3 优先规则（多维度）
| 维度 | 说明 |
|---|---|
| 课程优先 | 在某节次内排课时，优先选择指定课程（如上午前两节优先语数外） |
| 教师优先 | 在某节次内排课时，优先安排指定教师 |

### 2.4 合班规则
设置「科目 + 班级集合」后，这些班级的该科目必须安排在**同一节次**（体育合堂、选修合班）。

### 2.5 单双周规则
某年级设置单、双周课程组合。例：单周上道法，双周上自然。

### 2.6 课程互斥规则
为多个课程设置互斥关系，互斥的课程**不会在同一天内**排课。

### 2.7 预排规则（锁定）
预先为部分课程 / 教师指定固定时间位，算法必须保留这些安排（升旗、班会、校本课程）。

### 2.8 其它规则
| 规则 | 说明 |
|---|---|
| 教案齐平规则 | 同年级同科目各班的进度尽量对齐（同一科目在各班的周内位置接近） |
| 周任课规则 | 某科目在一周内的分布策略：**周内分散** / **周内集中** |
| 日任课规则 | 某科目在一天内的分布策略：**日内分散** / **日内集中** |

## 三、算法选型对照

| 算法 | 适用性 | 备注 |
|---|---|---|
| 贪心 | 简单场景、快速产出初始解 | 无回溯能力，局部最优；常用于阶段一 |
| 遗传算法 GA | 多约束、多目标优化 | 全局搜索、可并行；参数调优难、收敛慢 |
| 模拟退火 SA | 在初始解基础上做全局优化 | 通过概率接受劣解跳出局部最优；需设计冷却策略 |
| 整数规划 / CP-SAT | 精确求解、可证最优 | 规模大时慢，且引入较重的求解器依赖 |

> **本项目结论**：采用「贪心构造 + 模拟退火优化」两阶段方案，规则体系以本清单为完备性基线，按演示优先级分批实现。
